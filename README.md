# Бот-напарник для запуска дел

Telegram-бот: «body double» + запуск дел + прощающий трекер.
Сейчас реализован первый сценарий «Запусти меня».

## Как это работает

1. Пользователь пишет дело («помыть посуду»).
2. Бот отвечает одним микрошагом («Встань и возьми одну тарелку») и предлагает таймер на 10 минут.
3. Кнопки: «Погнали» / «Ещё меньше» / «Не сейчас».
4. Когда таймер сработал, приходит чек-ин: «Продолжаю» / «Сделано» / «Застрял(а)».
5. «Сделано» даёт тёплое подтверждение и выбор «Дальше» или «На сегодня хватит».
   «Застрял(а)» даёт совсем крошечный шаг на 2 минуты. Упрёков нет ни в одном исходе.

Кнопка «Перезапуск дня» закрывает всё незавершённое без счётчиков пропусков и предлагает выбрать одно дело.
Команда `/stop` останавливает текущую сессию.

## Запуск локально

```bash
python -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env   # впиши токен от @BotFather
python bot.py
```

## Запуск на VPS (Docker)

```bash
cp .env.example .env   # впиши токен
docker compose up -d --build
docker compose logs -f
```

База (SQLite) лежит в `./data`, таймеры хранятся в ней и переживают перезапуск.

## Структура

| Файл | Что внутри |
|---|---|
| `bot.py` | точка входа: БД, диспетчер, планировщик |
| `handlers.py` | сценарий: сообщения и кнопки, переходы статусов |
| `splitter.py` | правила дробления задач на микрошаги |
| `texts.py` | все тексты бота (тон правится здесь) |
| `keyboards.py` | кнопки |
| `scheduler.py` | чек-ины по таймеру |
| `db.py` | SQLite, таблица сессий |

## Как расширять правила дробления

В `splitter.py` в список `RULES` добавь строку: ключевые основы слов и 3 шага от самого лёгкого к более крупным.
Первое совпавшее правило побеждает. Если ничего не подошло, работает общий шаблон `GENERIC`.
